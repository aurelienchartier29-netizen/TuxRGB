TuxRGB 2.0.7 pour Windows
=========================

FRANÇAIS
--------
TuxRGB pour Windows 10 / 11 (64 bits) : la même application que sur Linux,
publiée en même temps et avec les mêmes correctifs.

Ce qui est identique à Linux : toute l'interface Material 3 Expressive,
les effets, les profils, le canevas spatial et le moteur OpenRGB embarqué
(OpenRGB 1.1, lancé par TuxRGB comme serveur privé).

Ce qui est propre à Windows :
  - Visualiseur audio : capture WASAPI de la sortie par défaut.
  - Synchro écran : écran principal (les jeux en plein écran exclusif
    restent noirs : utilisez le mode « fenêtré sans bordure »).
  - Zone de notification : icône Windows avec le même menu.
  - Extinction / veille : les LED passent à 0 % à l'arrêt, au redémarrage,
    à la fermeture de session et à la mise en veille, puis reviennent au
    réveil et au démarrage suivant.
  - Couleur d'accentuation : celle de Windows (Paramètres →
    Personnalisation → Couleurs), suivie en direct, ainsi que le mode
    clair / sombre.

Accès matériel :
  - Périphériques USB / HID (claviers, souris, contrôleurs USB) : rien à
    faire.
  - Carte mère et RAM (SMBus) : pilote PawnIO + droits administrateur.
    L'installateur peut installer PawnIO et configurer le « mode
    administrateur » (une tâche planifiée qui relance TuxRGB avec les
    droits administrateur sans invite à chaque démarrage). Sinon :
    Réglages → Accès matériel → Configurer l'accès.

Mises à jour : Réglages → Mises à jour → Rechercher. TuxRGB télécharge le
nouvel installateur depuis GitHub, vérifie sa somme SHA-256, l'exécute
(confirmation Windows) puis redémarre tout seul ; les réglages, OpenRGB,
PawnIO et le mode administrateur sont conservés. La vérification peut aussi
se faire automatiquement au démarrage (au plus toutes les 6 heures).

Fichiers :
  - Réglages : %APPDATA%\tuxrgb
  - Journaux et rapport matériel : %LOCALAPPDATA%\tuxrgb

Désinstallation : Paramètres Windows → Applications, ou le menu Démarrer →
TuxRGB → Désinstaller TuxRGB (les réglages et le pilote PawnIO sont
conservés).

ENGLISH
-------
TuxRGB for Windows 10 / 11 (64-bit): the same application as on Linux,
released at the same time with the same fixes.

Same as on Linux: the whole Material 3 Expressive interface, effects,
profiles, spatial canvas and the embedded OpenRGB 1.1 engine.

Windows specifics: WASAPI audio capture, primary-monitor screen sync,
Windows tray icon, LEDs off at shutdown / logoff / sleep (back on resume
and at the next start), live Windows accent colour and light/dark mode.
Motherboard and RAM need the PawnIO driver and administrator rights
(the installer can set both up; otherwise Settings → Hardware access →
Set up access).

Updates: Settings → Updates → Check. TuxRGB downloads the new installer
from GitHub, verifies its SHA-256, runs it (Windows confirmation) and
starts again by itself; settings, OpenRGB, PawnIO and administrator mode
are kept. The check can also run automatically at start-up.

Settings: %APPDATA%\tuxrgb – logs: %LOCALAPPDATA%\tuxrgb
