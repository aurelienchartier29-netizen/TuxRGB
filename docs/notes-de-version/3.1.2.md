Correctif Windows : la charge et la température du GPU, la température et la puissance du CPU s'affichent enfin (plus de « -- »), sur les afficheurs comme dans l'effet Moniteur matériel.

### Corrigé
- **Charge et température du GPU sous Windows**, pour toutes les cartes (AMD, NVIDIA, Intel) : TuxRGB les lit directement dans Windows, aux mêmes sources que le Gestionnaire des tâches. Rien à installer. Jusqu'ici, seules les cartes NVIDIA étaient lues.
- **Température et puissance du CPU sous Windows** (AMD Ryzen, Intel Core) : lues par le pilote **PawnIO**, que TuxRGB installe déjà pour la carte mère et la RAM, avec ses modules officiels signés (les mêmes que LibreHardwareMonitor). Il faut le **mode administrateur** (proposé par l'installateur, ou Réglages → Accès matériel → Configurer l'accès) : Windows ne donne ces valeurs à aucun programme sans pilote.
- Si LibreHardwareMonitor est ouvert, ses valeurs restent utilisées en priorité.

### Toujours valable
- 3.1.1 : installateur Windows sans aucun script (fausse alerte de Windows Defender).
- 3.1 : effet global ou effet propre par composant, rotation libre sur le canevas, page **Afficheurs** (NZXT Kraken, Corsair LCD, DeepCool — CH560 DIGITAL confirmé sous Linux et Windows).
