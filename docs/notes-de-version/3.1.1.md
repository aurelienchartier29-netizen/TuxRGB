Correctif Windows : l'installateur ne lance plus aucun script, pour que Windows Defender ne le prenne plus pour un virus.

### Corrigé
- **Windows Defender signalait l'installateur** comme une menace. C'était une fausse alerte : l'installateur lançait un script PowerShell (en contournant la stratégie d'exécution) pour télécharger OpenRGB et le pilote PawnIO, ce qui est exactement le comportement que les antivirus surveillent chez les logiciels malveillants. Désormais :
  - l'installateur ne lance **plus aucun script ni PowerShell** ;
  - **OpenRGB 1.1** est téléchargé par TuxRGB lui-même, en HTTPS, depuis sa source officielle (Codeberg / openrgb.org) ;
  - l'installateur officiel de **PawnIO**, signé par son auteur, est inclus dans celui de TuxRGB : plus rien à télécharger pour lui.

### Toujours valable
- Tout ce qu'apporte la 3.1 : effet global ou effet propre par composant, rotation libre sur le canevas, page **Afficheurs** (NZXT Kraken, Corsair LCD, DeepCool — le boîtier CH560 DIGITAL a été confirmé sur du vrai matériel).

### À savoir
- TuxRGB n'est pas encore signé numériquement (un certificat de signature est payant) : Windows SmartScreen peut afficher « Windows a protégé votre ordinateur » au premier lancement de l'installateur → **Informations complémentaires** → **Exécuter quand même**.
- Si Defender alerte encore, signalez la fausse alerte à Microsoft (lien dans le LIRE-MOI) : l'analyse prend en général un à trois jours, ensuite plus personne n'a l'alerte.

### Mise à jour
- Depuis la 2.0.5 : Réglages → Mises à jour → **Rechercher**.
- Depuis une version plus ancienne : téléchargez l'AppImage ou l'installateur Windows ci-dessous.
