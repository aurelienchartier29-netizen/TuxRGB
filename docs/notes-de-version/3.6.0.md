Un thème AMOLED, et sous Windows le même moteur OpenRGB économe que sous Linux.

### Thème AMOLED
- Réglages → Apparence → Thème : **AMOLED** rejoint Système, Clair et Sombre. C'est le thème sombre sur un fond **noir pur** : sur un écran OLED, ces pixels sont éteints. Les cartes et les champs restent à peine teintés de votre couleur d'accent, juste assez pour se détacher du fond, et le texte garde un contraste élevé.

### Windows : OpenRGB qui ne tourne plus à vide
- L'installateur contient désormais **OpenRGB 1.1 compilé par TuxRGB**, avec le correctif de la 3.5.0 : chaque contrôleur attend ses couleurs au lieu de vérifier mille fois par seconde s'il en a. La version officielle pour Windows règle en plus l'horloge du système à 0,5 ms pour que ces vérifications soient précises.
  - Mesuré sous Wine avec six contrôleurs et un effet fixe : environ **18 % d'un cœur → 0,4 %**, et 14 000 réveils par seconde → 290.
- **Rien n'est téléchargé pendant l'installation** : OpenRGB est inclus, comme le pilote PawnIO.
- Les mises à jour remplacent aussi ce moteur (une installation d'OpenRGB à vous n'est pas touchée).
- Comme la version officielle, OpenRGB a besoin du runtime Visual C++ de Microsoft, déjà présent sur la plupart des PC Windows.

### Pour les curieux
- OpenRGB, Qt 5.15 et Mbed TLS sont compilés depuis leurs sources, sous Linux, avec MinGW-w64 : `scripts/windows/build-openrgb-windows.sh`. Une seule ligne d'OpenRGB change pour ce compilateur (`third_party/patches/0002`). Le détail est dans `third_party/README.md`.
