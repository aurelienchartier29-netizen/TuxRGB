**Windows Beta Build** de TuxRGB 2.0.4 pour Windows 10 / 11 (64 bits).

> Linux reste la version principale et de référence de TuxRGB. Cette build Windows est une **bêta** : elle est maintenue en priorité pour les **correctifs de bugs majeurs**, les nouveautés arrivent d'abord sur Linux.

### Ce qui est identique à Linux
- Toute l'interface Material 3 Expressive (animations, couleurs dynamiques, français / anglais)
- Les 19 effets, les profils, le canevas spatial
- Le moteur OpenRGB 1.1, lancé par TuxRGB comme serveur privé

### Ce qui est propre à Windows
- Visualiseur audio par capture **WASAPI** de la sortie par défaut
- Synchro écran sur l'écran principal (les jeux en plein écran exclusif restent noirs : mode « fenêtré sans bordure »)
- Icône **Win32** dans la zone de notification, avec le même menu ; notifications en toasts
- LED à **0 %** à l'arrêt, au redémarrage, à la fermeture de session et à la mise en veille ; restaurées au réveil et au démarrage
- « Éteindre les LED en quittant » activé par défaut (désactivable dans Réglages → Démarrage)
- Couleur d'accentuation et mode clair / sombre de Windows, suivis en direct
- Carte mère et RAM : pilote **PawnIO** + **mode administrateur** (une seule confirmation UAC, puis plus aucune invite)

### Correctifs de cette mise à jour
- **Saturation 100 → 200 %** : la plage au-dessus de 100 % agit maintenant aussi sur les couleurs déjà pures (accent Windows comme #0078D4, arc-en-ciel…), qui ne changeaient plus du tout ; elles deviennent progressivement plus profondes
- **Arrêt du PC** : TuxRGB demande à Windows d'être prévenu le premier, avant OpenRGB (qui pouvait être fermé avant que les LED soient éteintes), et envoie le noir deux fois pour les contrôleurs lents (RAM, carte mère)

### Installation
1. Téléchargez `TuxRGB-2.0.4-win-beta-Setup.exe` ci-dessous
2. Double-cliquez dessus et suivez l'installateur ; il télécharge OpenRGB 1.1 et PawnIO depuis leurs sources officielles (connexion Internet nécessaire)
3. Windows SmartScreen peut afficher « Windows a protégé votre ordinateur » (installateur non signé) : **Informations complémentaires → Exécuter quand même**

Vérification : `Get-FileHash TuxRGB-2.0.4-win-beta-Setup.exe` doit donner la valeur du fichier `.sha256`.
