Première version publiée **en même temps pour Linux et Windows**, avec les mêmes correctifs. La version Windows sort de la bêta : interface, effets, profils et canevas identiques à Linux.

### Nouveautés (Linux et Windows)
- **Mises à jour intégrées** : Réglages → Mises à jour → **Rechercher**. TuxRGB interroge les versions publiées sur GitHub et prend le fichier de son système : l'AppImage sur Linux (remplacée sur place, puis redémarrage), l'installateur sur Windows (installation silencieuse, puis TuxRGB redémarre tout seul). Chaque téléchargement est vérifié avec sa somme SHA-256 avant de remplacer quoi que ce soit ; les réglages sont conservés
- Vérification automatique au démarrage (au plus toutes les 6 heures, désactivable) ; rien n'est installé sans votre accord. Une nouvelle version s'annonce sur l'accueil et par une notification
- Flatpak et paquets de distribution : la page de la version s'ouvre, la mise à jour passe par la logithèque

### Correctifs (Linux et Windows)
- **Saturation 100 → 200 %** : la plage au-dessus de 100 % agit maintenant aussi sur les couleurs déjà pures (arc-en-ciel, couleur primaire, couleur d'accentuation comme le bleu Windows #0078D4), qui ne changeaient plus du tout ; elles deviennent progressivement plus profondes. Les couleurs moins saturées gardent exactement le même rendu qu'avant

### Correctifs Windows
- **Arrêt du PC** : les LED s'éteignent vraiment. TuxRGB demande à Windows d'être prévenu le premier, avant OpenRGB (qui pouvait être fermé avant que les LED soient éteintes), et envoie le noir deux fois pour les contrôleurs lents (RAM, carte mère)
- Textes de l'interface parfois illisibles (police de secours de Windows) : corrigé
- « Éteindre les LED en quittant » activé par défaut et appliqué avant la fermeture d'OpenRGB
- Plus de mention « bêta » : nom du fichier `TuxRGB-2.0.5-Windows-Setup.exe`, Réglages et À propos
